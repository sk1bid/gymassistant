## Что за проект (одним абзацем)

Telegram-бот (aiogram 3, поллинг через SOCKS5) + Mini App (FastAPI, ES-модули без
сборки) в одном репозитории. Общая БД (PostgreSQL/SQLAlchemy async), общий слой
данных `database/orm_query.py`. Роли строго разделены: **Mini App** — весь UI
(тренировка, программы, каталог, история, графики), **бот** — точка входа и
**единственный, кто умеет уведомлять** (пинги отдыха, `workers/rest_notifier.py`).

## Незыблемые правила

- Пинг отдыха — **новое сообщение с удалением предыдущего**, никогда не
  `editMessageText` (edit не даёт ни пуша, ни вибрации → убивает весь смысл).
- Состояние тренировки **не хранится между запросами**: план = упражнения дня,
  факт = записанные подходы, текущий шаг = первое расхождение.
- id приходят с фронта — им нельзя верить, проверять владение через `ownership.py`.
- Даты хранятся naive-UTC, раскладываются по календарю в поясе пользователя
  (заголовок `X-Timezone`).
